## Publicar con GitHub Pages

1. Sube index.html, .nojekyll y README.md al repositorio quick-search-tools-privacy, rama main.
2. Abre Settings > Pages.
3. Selecciona Deploy from a branch, rama main, carpeta / (root), y guarda.
4. Cuando termine el despliegue, comprueba la página pública:
   https://pepotemastodonte.github.io/quick-search-tools-privacy/
5. Pega esa URL en el campo Política de Privacidad de Chrome Web Store.

La URL solo funcionará después de subir los archivos y activar GitHub Pages. Actualiza la política antes de incorporar pagos, licencias u otros tratamientos de datos.
